          SmartBraces, Brace Movement Optimization *SmartBraces* *smartbraces*

===========================================================================
0. Introduction ~
                                          *SmartBraces-intro* *smartbraces-intro*

This Vim plug-in makes

- the keys { and } jump to the beginning respectively end of the current
  paragraph (instead of, by default, the first empty line before respectively
  after it),
- the key ) jump to the end of the current sentence (instead of the start of
  the next sentence).

Pressed again at the beginning (or end) of a paragraph, { (or }) jumps to the
beginning (or end) of the previous (or next) paragraph. Counts work in Normal,
Visual and Operator-pending mode.

A sentence ends at a '.', '!' or '?', followed by any closing ')', ']', '"'
or ''', and then a space, a tab or the end of the line. A '.' right after a
digit or one of I, V and X, as in an enumeration, only ends a sentence at the
end of a line. As for Vim's own |sentence| motions, the end of a paragraph
also ends a sentence.

After an operator, } and ) are |inclusive|, so that, for example, d) deletes
the rest of the current sentence up to and including its final punctuation
mark, whereas { is |exclusive|, as Vim's own backward motions are.

===========================================================================
1. Config ~
                                    *SmartBraces-config* *smartbraces-config*

The following mappings with the following default values are available:
>
  nmap {  <Plug>(smartbraces-OpenBrace)
  xmap {  <Plug>(smartbraces-OpenBrace)
  omap {  <Plug>(smartbraces-OpenBrace)
  nmap }  <Plug>(smartbraces-CloseBrace)
  xmap }  <Plug>(smartbraces-CloseBrace)
  omap }  <Plug>(smartbraces-CloseBrace)

  nmap )  <Plug>(smartbraces-CloseParenthesis)
  xmap )  <Plug>(smartbraces-CloseParenthesis)
  omap )  <Plug>(smartbraces-CloseParenthesis)
<
No default mapping is created in a mode in which some key is already mapped
to the <Plug> mapping, or in which the key itself is already mapped. To
keep, for example, the native behavior of } after an operator, add
>
  onoremap } }
<
to your vimrc.

                                                        *g:smartbraces_spell*
If you prefer that the keys { and }, as well as ), jump to the beginning
respectively to the end of the current paragraph, respectively sentence, only
inside spellchecked buffers, but work as usual otherwise, add
>
  let g:smartbraces_spell = 1
<
to your vimrc.
